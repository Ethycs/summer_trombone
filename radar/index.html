How these numbers are computed

Per-line survival

For each rewritten line $i$ (a line deleted or replaced by some commit $c$ in the window), let $t_{\text{author}}(i)$ be the original author timestamp recovered from git blame at the parent commit, and $t_{\text{rewrite}}(c)$ be the committer timestamp of $c$.

$$ \mathrm{survival}_i = \max\!\left(0,\ \tfrac{t_{\text{rewrite}}(c) - t_{\text{author}}(i)}{86400}\right) \text{ days} $$

Penalty for downstream churn

Each line is discounted by activity on the same file inside the window: $f_i$ = total follow-up commits touching the file, $b_i$ = commits whose subject matches a bugfix pattern, $g_i$ = distinct bug-labeled issues referenced by those commits.

$$ \mathrm{penalty}_i \;=\; 1 \;+\; \alpha\,\ln(1+f_i) \;+\; \beta\,\ln(1+b_i) \;+\; \gamma\,\ln(1+g_i) $$

with $\alpha = 0.5$, $\beta = 1.5$, $\gamma = 2.5$.

$$ \mathrm{discounted}_i \;=\; \frac{\mathrm{survival}_i}{\mathrm{penalty}_i} $$

Per-author roll-up in a window

Let $W_a$ be the set of events attributed to author $a$ in the active window, and $N_a = |W_a|$.

$$ \overline{\mathrm{survival}}_a \;=\; \frac{1}{N_a} \sum_{i \in W_a} \mathrm{survival}_i \quad\quad \mathrm{impact}_a \;=\; \sum_{i \in W_a} \mathrm{discounted}_i $$

What "durable impact" means

$\mathrm{impact}_a$ is the headline number: it sums, across every line an author wrote that later got rewritten in the window, the number of days that line lived — after each line is discounted by how much follow-up churn, bugfix activity, and bug-issue traffic its file has attracted.

So a high $\mathrm{impact}_a$ comes from authoring code that survives a long time in quiet files. Code that lives long in churny / bug-heavy files counts much less. Code that dies quickly counts very little regardless of where it lived. The radar's $\text{durable impact}$ axis is just this same total, rescaled to 0..100.

Normalisation to 0..100 (what the leaderboard shows)

Each column is rescaled against the maximum across authors retained in this window (top 50 by raw impact), so the leader sits at 100 and everyone else is relative.

$$ \text{durable impact}_a \;=\; 100 \cdot \frac{\mathrm{impact}_a}{\max_a\,\mathrm{impact}_a} $$ $$ \text{longevity}_a \;=\; 100 \cdot \frac{\overline{\mathrm{survival}}_a}{\max_a\,\overline{\mathrm{survival}}_a} $$ $$ \text{sample conf.}_a \;=\; 100 \cdot \frac{\ln(1 + N_a)}{\ln(1 + \max_a N_a)} $$

The $\ln$ on sample confidence is so an author with 10$\times$ more lines reads as "more confident" without dominating linearly. The other axes use the same 0..100 scaling so the radar shape carries the comparison, not the axis units.
